# IRS 工作流迁移验收方案

## 状态分类定义
- **NOT_RUN**：尚未执行校验。
- **BLOCKED**：前置条件不满足或被策略阻断。
- **PASS**：具备完整可验证证据并经审查通过。无真实执行证据绝不推断为 PASS。

## 验收项映射表

### V01: 基线不变性验证 (持续验证)
- **要求**：冻结的产品标识与代码资产保持不变，原有未跟踪文件完整保留；经批准的控制文件变更作为相对于备份的授权差异记录，不强制要求所有控制文件哈希绝对相等。
- **状态**：NOT_RUN

### V02: 交接规范验证
- **要求**：new00 必须精确陈述基线状态、最新暂停策略、授权边界、凭据记录以及已知未知项（包含 HTML 浏览器视觉验证）。
- **状态**：NOT_RUN

### V03: 暂停策略权威性验证 (持续验证)
- **要求**：最新生效的暂停策略具有最高权威性，强制覆盖旧的自动播放策略与过期配额限制。
- **状态**：NOT_RUN

### V04: 候选变更与请求绑定验证
- **要求**：重复相同请求不得产生重复处理；提交哈希、目录树、凭据或范围发生变动时，必须重新发起完全匹配的审查流程。
- **状态**：NOT_RUN

### V05: 工具执行与系统隔离验证
- **要求**：采用实际操作系统级与子进程级隔离机制，而非单纯白名单判定；隔离环境下的纯文本降级不视为工具执行成功。
- **状态**：NOT_RUN

### V06: 真实审核与证据链验证
- **要求**：自动化测试失败或缺少真实截图凭据直接阻断发布；代理视觉与间接推断不等同于人类已审阅图像证据。
- **状态**：NOT_RUN

### V07: 上下文隔离与跨模块约束验证
- **要求**：受控边界的独立任务必须严格遵循并保持适用的跨模块架构约束。
- **状态**：NOT_RUN

### V08: 实际角色可见性与单一所有权验证 (演练与切换后只读复核)
- **要求**：具备真实可见的角色路由与单一所有者分配，明确 CLI 与桌面会话（desktopchat）职责隔离。
- **状态**：NOT_RUN

### V09: 重启幂等性与空闲验证
- **要求**：进程重启保持幂等性；无外部事件触发时模型调用必须为零；系统错误保持可见并留存。
- **状态**：NOT_RUN

### V10: 完整可比成本与质量度量验证
- **要求**：记录任务全周期的可比用量与质量指标，未知缓存 token 明确标记为 unknown，不自动推断未测试通过的状态。
- **状态**：NOT_RUN
